# Product Requirements Document

## Vision

Build India's most user-friendly AI-assisted managed matrimonial platform: not a dating app, not a generic CRUD app, and not a clone of any existing matrimonial website.

Lovekush should operate as a matrimonial business operating system where technology supports families, relationship managers, verification, privacy, matching, profile sharing, and long-term customer lifecycle management.

## Primary KPI

The most important Phase 1 KPI is:

> Percentage of serious families who complete registration and submit a high-quality profile.

Secondary KPIs:

- Draft-to-submitted conversion rate
- Average onboarding completion time
- Section completion rate
- Profiles submitted with photos
- Profiles submitted with enough family/preference details
- Profiles requiring admin correction
- Mobile completion rate

## Product pillars

1. Guided onboarding before feature depth
2. Trust before growth
3. Privacy by default
4. Human-assisted AI, not AI replacement
5. CRM-backed operations
6. Structured data for matching and analytics
7. Mobile-first family experience

## Phase 1A Scope

Phase 1A focuses on onboarding conversion.

Included:

- Guided onboarding shell
- Draft save
- Resume later
- Profile checklist
- Profile preview
- Section-based editing
- Mobile-first UI improvements

Excluded:

- Full CRM
- AI matching
- PDF biodata
- WhatsApp integration
- Payments
- Full database normalization

## Phase 1B Scope

Phase 1B adds essential trust and security foundations.

Included:

- Admin authentication
- Staff roles
- RLS foundation
- Audit logs
- Profile lifecycle statuses

## Success criteria

A Phase 1 profile creator should feel:

- Simple enough for parents
- Fast enough for mobile users
- Trustworthy enough for sensitive data
- Clear enough to resume later
- Guided enough to improve quality without consultant intervention
