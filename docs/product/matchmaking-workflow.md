# Matchmaking Workflow

## Matching philosophy

Lovekush matching should combine structured compatibility, family preferences, privacy rules, AI explanation, and human relationship manager judgement.

## Match pipeline

```text
Active profile
→ hard filter candidates
→ weighted score candidates
→ generate score breakdown
→ detect watch points
→ RM review
→ shortlist
→ interest request
→ family response
→ introduction
→ meeting
→ feedback
→ next action
```

## Hard filters

- Gender compatibility
- Age range dealbreakers
- Religion/community dealbreakers
- Marital status dealbreakers
- Location dealbreakers
- Hidden/blocked profiles
- Privacy restrictions

## Weighted factors

- Age compatibility
- Religion/community compatibility
- Education
- Occupation
- Income range
- City/state/country
- Family type
- Family values
- Diet
- Smoking/drinking
- Languages
- Hobbies/interests
- Partner expectations

## Match explanation structure

```text
Compatibility: 92%

Strengths
- Compatible age range
- Education preference matched
- Similar lifestyle
- Family values aligned

Watch points
- Different current city
- Income expectation should be confirmed

Recommended action
- RM should verify relocation flexibility before introduction
```

## Human approval

AI or algorithmic match suggestions should not automatically create introductions. Relationship managers approve high-value introductions.
