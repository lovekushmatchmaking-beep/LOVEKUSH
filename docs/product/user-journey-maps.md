# User Journey Maps

## Journey 1: Parent creating profile for son/daughter

```text
Landing
→ Register
→ Welcome Setup
→ Basic Details
→ Save Draft
→ Education & Career
→ Family Background
→ Photos
→ Preview
→ Submit for Review
→ Dashboard Review Status
```

### Emotional goals

- Feel safe
- Understand why data is needed
- Avoid typing fatigue
- Trust Lovekush review process
- Believe profile quality will improve matches

### Friction points to remove

- Too many fields on first screen
- Unknown time commitment
- Fear of exposing phone/photos
- Difficulty writing About Me
- Lack of resume later option

## Journey 2: Candidate self-registering

```text
Landing
→ Register
→ Welcome Setup
→ Complete Basic Details
→ Skip heavy family details temporarily
→ Add photos
→ Preview public profile
→ Submit or continue improving
```

### Design notes

Younger users can fill faster, but may not know family details. The UX should allow partial completion while clearly marking missing family details.

## Journey 3: Incomplete user returning later

```text
Login
→ Profile Setup Home
→ Continue from last incomplete section
→ Autosave
→ Preview
→ Submit
```

### Success metric

Return-to-completion rate.

## Journey 4: Admin reviewing submitted profile

```text
Staff Login
→ Review Queue
→ Profile Detail
→ Check missing fields/photos
→ Approve / Needs Changes / Block
→ Audit event created
→ User sees updated status
```

## Journey 5: Relationship manager-assisted profile improvement

```text
RM Dashboard
→ Incomplete Profiles
→ Open Customer
→ Add note/call log
→ Request missing detail
→ Mark follow-up
→ User completes detail
→ Profile quality improves
```
